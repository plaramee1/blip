# Blip

Blip is a native Mac app for working with AI coding agents. It runs Claude Code,
Codex, Cursor, local models and other providers in one window, next to a
terminal, a browser, a wiki and a memory store. The memory store is a folder of
small notes that every agent reads when it starts, so agents stop forgetting
between conversations, and you can see and edit everything they remember.

This repository is Blip's **public home for releases and feedback**. Blip's
source code is not published here.

## Download

Get the latest notarized `Blip-<version>.dmg` from
[Releases](https://github.com/plaramee1/blip/releases/latest). Blip checks this
page for updates by itself (Settings → Updates).

Blip needs macOS on Apple silicon. It starts with a 30-day free trial with every
feature.

## Report a bug or ask for a feature

The easiest way is from inside the app: **Help ▸ Report a Bug…** or
**Help ▸ Request a Feature…**. These fill in your Blip and macOS versions for
you. You can also [open an issue](https://github.com/plaramee1/blip/issues/new/choose)
directly.

- **Issues are public.** Don't paste API keys, tokens, passwords, private
  memories or file contents you wouldn't publish.
- Search the [existing issues](https://github.com/plaramee1/blip/issues?q=is%3Aissue)
  first, and add a 👍 to the one that matches rather than opening a new one.
- A bot labels new issues and may ask for missing details. A person reads every
  issue that is labelled `triaged`.

## Security

Please don't report security problems in a public issue. See
[SECURITY.md](SECURITY.md) for private reporting.
